## Важные замечания

Среда проверки 08.10.2026 не разрешала доменные имена внешних сайтов вообще, включая GitHub и Google. Нельзя делать из этого вывод о поломке домена АМАПС. Отдельные веб-проверки сайта тоже не дали надёжного HTTP-ответа. Изменения в GitHub подтверждены чтением файлов, не проверкой публикации.

Обычное обновление исходников и создание файла IndexNow сами по себе не являются доказательствами регистрации в Яндекс Вебмастере, Google Search Console или индексации поисковиками. Никаких платных услуг не заказывали.

## Контрольный порядок

1. Проверить публичные HTTP-ответы главной, трёх страниц, sitemap.xml, robots.txt и ключа IndexNow.
2. Добавить ресурс в Яндекс Вебмастер и Google Search Console через аккаунты владельца.
3. Получить и установить уникальные проверочные коды; подтвердить права.
4. Передать sitemap.xml в оба кабинета.
5. Выполнить IndexNow-уведомление и проверить код ответа, затем контролировать фактическую индексацию.
